# An until-end-of-turn effect added through AddContinuousEffectToGame follows its target to a new object

Engine: XMage (magefree/mage). Upstream base: master `2a96b0ac12` (2026-11-22). Mirror branch: [`adams-shaun/mage:upstream/continuous-effect-copied-target-zcc`](https://github.com/adams-shaun/mage/tree/upstream/continuous-effect-copied-target-zcc) at `e8e1eefc8e`.

## Oracle text

Stomped by the Foot:

> Kicker—Sacrifice an artifact or creature. (You may sacrifice an artifact or creature in addition to any other costs as you cast this spell.)
> Target creature gets -2/-2 until end of turn. If this spell was kicked, that creature gets -5/-5 until end of turn instead.

## Comprehensive Rules

> 611.2c If a continuous effect generated by the resolution of a spell or ability modifies the characteristics or changes the controller of any objects, the set of objects it affects is determined when that continuous effect begins. After that point, the set won’t change. (Note that this works differently than a continuous effect from a static ability.) A continuous effect generated by the resolution of a spell or ability that doesn’t modify the characteristics or change the controller of any objects modifies the rules of the game, so it can affect objects that weren’t affected when that continuous effect began. If a single continuous effect has parts that modify the characteristics or changes the controller of any objects and other parts that don’t, the set of objects each part applies to is determined independently. Example: An effect that reads “All white creatures get +1/+1 until end of turn” gives the bonus to all permanents that are white creatures when the spell or ability resolves— even if they change color later—and doesn’t affect those that enter the battlefield or turn white afterward. Example: An effect that reads “Prevent all damage creatures would deal this turn” doesn’t modify any object’s characteristics, so it’s modifying the rules of the game. That means the effect will apply even to damage from creatures that weren’t on the battlefield when the continuous effect began. It also affects damage from permanents that become creatures later in the turn. 

> 400.7. An object that moves from one zone to another becomes a new object with no memory of, or relation to, its previous existence. This rule has the following exceptions. 

## What happens

`Mage/src/main/java/mage/abilities/effects/common/AddContinuousEffectToGame.java` (at `2a96b0ac12`) copies the
one-shot effect's target pointer into the continuous effects it adds. `OneShotEffect.initNewTargetPointer()` has
already marked that pointer initialized, before the spell chose targets, so the copy arrives with
`initialized = true` and an empty zone-change-counter map. `ContinuousEffectImpl.init` then skips its own
target-pointer init, `isOutdatedTarget` sees no recorded zone-change counter ("any"), and the effect keeps
applying to the card after it dies and returns as a new object (CR 400.7). CR 611.2c says the affected set is
locked in when the effect begins.

64 Mage.Sets classes use `AddContinuousEffectToGame`. Our farm rows: Pain 101 + a -X/-X spell on the same creature
(two rows); the LCI pair Fungal Fortitude + Join the Dead shows the same thing.

## Repro

1. Player A controls Squirrelanoids and four Swamps. A casts Pain 101 on it ("When this creature dies, return it
   to the battlefield tapped"), then Stomped by the Foot (unkicked, -2/-2) on it.
2. It dies, Pain 101's granted trigger returns it tapped.
3. Expected: the returned creature is a new object; the -2/-2 does not apply; it survives as a tapped 1/1.
   Actual: the -2/-2 follows it, it dies again and stays in the graveyard.

`Pain101StompedTest` below fails on master
(`Permanents counts for PlayerA are not equal (Squirrelanoids) expected:<1> but was:<0>`) and passes with the fix.

## Test

Added with the fix: `Mage.Tests/src/test/java/org/mage/test/cards/single/tmt/Pain101StompedTest.java`

```java
package org.mage.test.cards.single.tmt;

import mage.constants.PhaseStep;
import mage.constants.Zone;
import org.junit.Test;
import org.mage.test.serverside.base.CardTestPlayerBase;

public class Pain101StompedTest extends CardTestPlayerBase {
    @Test
    public void test_ReturnedCreatureIsNotHitAgainByTheBoost() {
        addCard(Zone.BATTLEFIELD, playerA, "Swamp", 4);
        addCard(Zone.BATTLEFIELD, playerA, "Squirrelanoids");
        addCard(Zone.HAND, playerA, "Pain 101");
        addCard(Zone.HAND, playerA, "Stomped by the Foot");
        castSpell(1, PhaseStep.PRECOMBAT_MAIN, playerA, "Pain 101", "Squirrelanoids");
        waitStackResolved(1, PhaseStep.PRECOMBAT_MAIN);
        castSpell(1, PhaseStep.PRECOMBAT_MAIN, playerA, "Stomped by the Foot", "Squirrelanoids");
        setChoice(playerA, false); // not kicked: -2/-2
        waitStackResolved(1, PhaseStep.PRECOMBAT_MAIN);
        setStopAt(1, PhaseStep.BEGIN_COMBAT);
        setStrictChooseMode(true);
        execute();
        assertPermanentCount(playerA, "Squirrelanoids", 1);
        assertTapped("Squirrelanoids", true);
        assertPowerToughness(playerA, "Squirrelanoids", 1, 1);
        assertGraveyardCount(playerA, "Squirrelanoids", 0);
        assertGraveyardCount(playerA, "Pain 101", 1);
        assertGraveyardCount(playerA, "Stomped by the Foot", 1);
    }
}
```
